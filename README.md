# TextSpace
TextSpace is a full-stack social media application where users can create posts, follow others, chat in real-time, and manage personalized profiles. Built using React, Node.js, Express, MongoDB, and Socket.IO, it delivers a smooth and modern social experience.



# TextSpace – Social Media Web App  
A fully functional social interaction platform featuring authentication, posting, following, and real‑time chat.

---

## 🚀 Features  
- 🔐 User Authentication (Register & Login)  
- 📝 Create Posts  
- ❤️ Like / Unlike Posts  
- 👤 Follow / Unfollow Users  
- 💬 Real‑time Chat (Socket.IO)  
- 📄 User Profiles  
- 🎯 Suggested Creators  
- 🗂️ MongoDB Database Integration

## 📦 Installation  

### 1️⃣ Clone the repository  
```bash
git clone https://github.com/yourusername/TextSpace.git
cd TextSpace
```

### 2️⃣ Install backend dependencies  
```bash
cd backend
npm install
```

### 3️⃣ Install frontend dependencies  
```bash
cd ../frontend
npm install
```

### 4️⃣ Setup `.env` in backend  
```
MONGO_URI=your_mongo_connection_string
JWT_SECRET=your_secret_key
PORT=5000
```

### 5️⃣ Run backend  
```bash
npm start
```

### 6️⃣ Run frontend  
```bash
npm run dev
```
